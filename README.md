# Movies API

Бэкенд-приложение для управления каталогом фильмов. Проект разработан с использованием FastAPI и асинхронной работы с SQLite. 

Главная идея при разработке заключалась не просто в том, чтобы "заставить код работать", а в использовании чистой архитектуры: разделение логики на роутеры, репозитории и схемы, а также применение миграций Alembic.

## Основные возможности
- Полноценный CRUD для сущности "Фильм" (создание, чтение, обновление, удаление).
- Валидация всех входящих и исходящих данных через Pydantic.
- Фильтрация фильмов по жанру и году выпуска.
- Сортировка списка фильмов (по рейтингу или году).

## Тех стек
- **язык:** Python 3.14.3
- **фреймворк:** FastAPI
- **база данных:** SQLite
- **ORM:** SQLAlchemy
- **миграции:** Alembic
- **валидация:** Pydantic V2
- **сервер:** Uvicorn

## Структура проекта
```text
movies_api/
├── alembic/                 # Файлы миграций базы данных
├── src/
│   ├── __init__.py
│   ├── main.py              # точка входа в приложение
│   ├── database.py          # настройка подключения и сессий БД
│   ├── models/              # SQLAlchemy модели (описание таблиц)
│   ├── schemas/             # Pydantic схемы для валидации данных
│   ├── repositories/        # слой доступа к данным (CRUD-операции)
│   └── routers/             # API эндпоинты
├── .env
├── alembic.ini              # конфигурация Alembic
├── requirements.txt         # библиотеки проекта
└── .gitignore
```

## Быстрый старт
1. Клонировать репозиторий
```text
git clone https://github.com/kVOnz/movies_api.git
cd movies_api

2. Создать и активировать venv
python -m venv .venv или py -m venv .venv
.venv\Scripts\activate

3. Установить библиотеки
pip install -r requirements.txt

4. Применить миграцию
alembic upgrade head

5. Запустить сервер или зайти через Swagger
uvicorn movies_api.src.main:app --reload
http://127.0.0.1:8000/docs
```
